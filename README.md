# Project Finding Nemo

Search for the better search.

This folder contains a static, shareable website for the IntelligenceBank search-strategy assignment.

## Live site

https://clintongwen.github.io/project-finding-nemo/

## Open the site

Open `dist/index.html` in any modern browser. The site is self-contained, so it does not need a server or internet connection for the main experience.

## Share it

Use `finding-nemo-search-strategy-site.zip` as the email/share package. Recipients can unzip it and open `index.html`.

## Present it

The landing page is the main presentation. It follows the assessment deliverables in order: problem overview, discovery and validation, competitive analysis, solution exploration, success measurement, implementation and organisational leadership.

Each section uses short presentation points. Use its evidence link, or the detailed evidence section at the bottom, when someone asks for the supporting analysis.

## Notes

- The visual style is clean and IntelligenceBank-inspired, while the Finding Nemo theme is expressed through the search journey rather than cartoon imagery.
- The site intentionally uses no build tooling so it is easy to email, archive or host as a plain static site.
